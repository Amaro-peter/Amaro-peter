# Featured Projects

## 🚀 TDDAgents
Multi-agent system for automating Test-Driven Development workflows.

Pipeline:

Code Generation  
→ Automated Testing  
→ Iterative Self-Correction

**Stack:** Python • LLM Agents • LangGraph

## 🔐 Web Cryptography (MessageApp)
Full-stack web application for end-to-end encrypted messaging, implementing advanced cryptography algorithms including RSA and post-quantum cryptography (Crystal-Kyber ML-KEM).
**Stack:** Java • Spring Boot • React • TypeScript • Vite[cite: 1]

## 📱 UFF Mobile Plus
Mobile application designed for Universidade Federal Fluminense (UFF) students. It features essential academic modules, including the Digital Student ID (Carteirinha Digital) and university bus routes/schedules (BusUFF).
**Stack:** Flutter • Dart • Firebase[cite: 2]

## ⛪ Evangelismo Digital Backend
Robust and scalable backend API built with Clean Architecture principles. It features background job processing queues for emails, Redis caching, rate limiting, and relational database management.
**Stack:** Node.js • TypeScript • Fastify • Prisma (PostgreSQL) • Redis • BullMQ • Docker[cite: 3]
